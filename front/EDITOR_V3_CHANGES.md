# Editor V3 — Cubase-style selection and keyboard workflow

- Shift/Ctrl/Cmd-click multi-selection.
- Marquee rectangle selection on empty piano-roll space.
- Ctrl/Cmd+A selects all notes; Escape clears selection.
- Group drag moves every selected note together.
- Hold Shift while dragging to constrain movement horizontally.
- Arrow keys move selected notes: left/right 10 ms, up/down 1 semitone.
- Shift+left/right moves 100 ms; Ctrl/Cmd+left/right moves 1 second.
- Shift+up/down transposes one octave.
- Delete/Backspace removes the complete selection.
- Ctrl/Cmd+Z undo; Ctrl/Cmd+Shift+Z and Ctrl/Cmd+Y redo.
- Ctrl/Cmd+C/X/V internal note copy/cut/paste.
- Ctrl/Cmd+D duplicates the selected notes.
- Ctrl/Cmd+S saves; Space toggles playback; Home/End seek song bounds.
- Multi-note drag is a single undo transaction.
- Selection-only clicks no longer create empty undo records.
