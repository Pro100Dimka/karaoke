# Editor V6

- Removed the vertical editor control rail and moved controls into a compact horizontal DAW top deck beside SongStrip.
- Reduced editor icon buttons and matched them to the application theme.
- Kept monitoring dials inline in the top deck; selection/syllable editing is compact and horizontal.
- Reworked piano roll density and piano keyboard styling to reduce oversized visual gaps.
- Added note audition on piano key click, note click, drag/pitch change, resize, arrow/nudge and transpose.
- Replaced native scrollbars with Cubase-like overlay horizontal/vertical scroll tracks with draggable thumbs.
- Kept horizontal and vertical zoom controls integrated into the corresponding scroll edges.
- Default vertical zoom reduced for a denser piano roll.
- Added V6 contract tests for layout, audition and custom scrollbars.
