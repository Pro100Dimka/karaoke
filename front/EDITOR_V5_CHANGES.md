# Editor V5

- Premium two-column layout: compact control rail + full piano-roll workspace.
- Removed right inspector and left hotkey-help block.
- Moved syllable assignment into a compact selection card on the left.
- Reworked toolbar, monitoring dials, header, notes, scrollbars, transport and zoom panel styling.
- Fixed playhead synchronization by driving it from active audio playback plus `timeupdate` fallback.
- Playhead can now be grabbed and dragged horizontally to seek.
- Ctrl + mouse wheel changes vertical zoom.
- Ctrl + Shift + mouse wheel changes horizontal zoom.
- Wheel zoom preserves the point under the mouse cursor.
- Kept existing multi-selection, marquee, group drag, resize and Cubase-style hotkeys.
