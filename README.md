# Karaoke Studio

Локальное desktop-приложение для караоке: библиотека песен, обработка треков,
вокальная MIDI-мелодия, запись исполнения и анализ попадания в ноты.

## Быстрый запуск разработки

В корне проекта запустите:

```bat
start-dev.bat
```

Скрипт завершает прежний backend на порту `8000`, проверяет офлайн-модели,
запускает API, Vite и Electron. В режиме разработки ошибки backend видны в том же
окне терминала. DevTools при этом не открываются автоматически.

## Первый запуск на новом компьютере

Нужны Node.js (LTS), Python 3.11+ и FFmpeg в `PATH`. В PowerShell из корня
проекта выполните:

```powershell
cd backend
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-dev.txt
cd ..\front
npm install
cd ..
start-dev.bat
```

При первом запуске `start-dev.bat` скачает только отсутствующие модели GAME,
Demucs и Whisper. Они не попадают в Git. Обработка использует NVIDIA GPU, если
она доступна, и безопасно переключается на CPU на других компьютерах.

## Проверка качества

Перед изменениями или сборкой выполните:

```bat
scripts\check.bat
```

Команда последовательно собирает frontend и запускает Ruff, mypy, pytest и
`pip check`. Не запускайте несколько проверок параллельно: Vite использует одну
папку `front\dist`.

## Сборка офлайн-установщика

```bat
build-installer.bat
```

Скрипт собирает backend, ASIO-мост и Electron-установщик. Для этого нужны
Visual Studio Build Tools (C++), CMake/Ninja из них и FFmpeg в `PATH`.
Установщик находится в `release\Karaoke Studio Setup 1.0.0.exe`, предлагает
обычный выбор папки установки и включает подготовленные модели для работы без
интернета.

## Структура

- `front/` — React-интерфейс и Electron-оболочка.
- `backend/app/` — FastAPI, база данных и прикладные сервисы.
- `backend/AI/` — обработка песен, текста, MIDI и анализ исполнения.
- `backend/engines/` — опциональные движки точного MIDI и ASIO-мост.
- `scripts/` — служебные сценарии проверки и подготовки моделей.

Локальные модели, виртуальные окружения, пользовательские песни, база данных,
логи, результаты сборки и релизы намеренно исключены из Git.

## Диагностика

- Если `start-dev.bat` сообщает об отсутствии окружения, выполните раздел
  «Первый запуск на новом компьютере».
- Если сборка установщика не находит FFmpeg, добавьте папку с `ffmpeg.exe` в
  системную переменную `PATH` и откройте новый терминал.
- Для минимальной задержки микрофона в приложении выберите ASIO-драйвер
  аудиоинтерфейса. При отсутствии ASIO приложение использует Windows/PortAudio.
