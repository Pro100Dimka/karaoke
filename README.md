# A&D Voice

Локальное desktop-приложение для караоке: библиотека песен, AI-разделение вокала,
распознавание и выравнивание текста, MIDI-мелодия, запись исполнения и онлайн-комнаты.

## Запуск разработки

```bat
start-dev.bat
```

Скрипт проверяет локальные AI-ресурсы, запускает FastAPI, Vite и Electron. DevTools
автоматически не открываются.

## Проверки

```bat
scripts\check.bat
```

Проверка включает frontend lint, форматирование, архитектурные аудиты, production
build, Ruff, mypy и аудит Python-зависимостей.

## Сборка установщика

```bat
build-installer.bat
```

Компактный ISO содержит приложение и AI-runtime. Во время первой установки он
один раз параллельно скачивает закреплённые версии моделей из их официальных
публичных репозиториев Hugging Face, проверяет файлы и сохраняет их локально.
Последующая обработка полностью локальная, бесплатная и работает без интернета;
качество совпадает с прежней полной офлайн-сборкой.

Это единственная публичная команда сборки. Скрипт сам сравнивает отпечатки
backend, frontend, Electron, ASIO, моделей и установщика, пересобирает только
изменившиеся компоненты и создаёт один актуальный offline ISO в `release/`.

Финальный единственный файл появляется в `release/`. Внутри ISO находятся компактный
`Setup.exe`, архив приложения и необходимые runtime-файлы; модели в ISO не дублируются.

### Подпись Windows

Production-релиз следует подписывать доверенным Authenticode-сертификатом:

```bat
set ADVOICE_SIGN_PFX=C:\secure\publisher-certificate.pfx
set ADVOICE_SIGN_PASSWORD=секрет
set ADVOICE_REQUIRE_SIGNING=1
build-installer.bat
```

Без сертификата локальная тестовая сборка создаётся, но Windows укажет неизвестного
издателя. Самоподписанный сертификат не заменяет доверенную production-подпись.

## Структура проекта

- `backend/` — только Python/FastAPI-код, AI-пайплайн и нативный ASIO-bridge.
- `front/` — только React/Electron-код и статические UI-ресурсы.
- `scripts/` — проверки, загрузка ресурсов, подпись и шаблон установщика.
- `downloads/` — загруженные runtime, модели, MSST и большое фоновое видео; не хранится в Git.
- `karaoke_songs/` — пользовательская библиотека и записи; не хранится в Git.
- `data/` — локальная база и настройки режима разработки; не хранится в Git.
- `build/` — все промежуточные frontend/backend/Electron-артефакты; не хранится в Git.
- `release/` — только готовый установщик и SHA-256; не хранится в Git.

После обработки оригинал не дублируется в отдельной `full_songs`: нормализованный файл
хранится внутри каталога песни. В установленной программе пользовательские данные
находятся в `%LOCALAPPDATA%\A&D Voice`, поэтому обновление приложения их не удаляет.

## Offline AI

В релиз включаются только используемые ресурсы: Qwen3-ASR-0.6B,
Qwen3-ForcedAligner-0.6B, Mel-Band RoFormer и MSST. Все компоненты используют единый
PyTorch runtime с CUDA при наличии совместимой NVIDIA GPU и автоматически работают на CPU
на остальных компьютерах.
