# Karaoke Studio

Локальное desktop-приложение для караоке: библиотека песен, обработка трека,
MIDI-мелодия, запись исполнения и анализ попадания в ноты.

## Запуск разработки

Из корня проекта запустите:

```bat
start-dev.bat
```

Скрипт завершает старый backend на порту `8000`, запускает API и открывает
Electron-клиент.

## Проверка проекта

```bat
check.bat
```

Команда собирает frontend и запускает Ruff, mypy, pytest и проверку зависимостей.

## Сборка установщика

```bat
build-installer.bat
```

Сначала собирается backend, затем Electron-приложение с установщиком.
Если модель GAME отсутствует в чистом клоне, скрипт сам скачает и проверит её
по контрольной сумме перед сборкой. Модель попадёт в ресурсы установщика, а не в Git.

## Структура

- `front/` — React + Electron интерфейс;
- `backend/app/` — FastAPI, API и прикладная логика;
- `backend/AI/` — обработка песен, текста, MIDI и оценка исполнения;
- `backend/engines/game/` — необязательный ONNX-движок точного извлечения мелодии.

## Обработка мелодии

При наличии локального GAME-движка обработка автоматически использует GPU NVIDIA
или CPU. Если он не установлен либо недоступен, приложение без ошибки переключается
на встроенный pYIN-анализатор. Для принудительного отключения GAME задайте
`SONGAPP_MIDI_ENGINE=pyin`.

Локальные модели, виртуальные окружения, пользовательские песни, база данных, логи
и результаты сборки специально исключены из Git.
