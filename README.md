# Karaoke Studio

Локальное desktop-приложение для караоке: обработка песен, MIDI-мелодия,
запись исполнения и анализ точности.

## Быстрый старт

После установки зависимостей запускайте из корня проекта:

```bat
start-dev.bat
```

Скрипт завершает предыдущий backend на порту 8000, запускает backend из
локального виртуального окружения и открывает Electron-клиент.

## Проверка качества

```bat
check.bat
```

Команда собирает frontend и запускает Ruff, Mypy, Pytest и проверку
согласованности Python-зависимостей.

## Сборка установщика

```bat
build-installer.bat
```

Скрипт сначала собирает backend в `backend/dist/KaraokeBackend`, затем
упаковывает Electron-приложение. Промежуточная папка `backend/build` не
хранится в Git и может безопасно пересоздаваться.
